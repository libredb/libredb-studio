LibreDB Studio brings a SQL IDE to Rancher-managed Kubernetes clusters: browse schemas, query forty-two engines, no desktop app. Installs from the Rancher Apps catalog: first-run admin credentials are generated and logged; production sets its secrets. Built and commercially supported by LibreDB.
  • Forty-two engines: PostgreSQL, MySQL, Oracle, Db2 LUW, SQL Server, SQLite, libSQL, DuckDB, MongoDB, Redis, Couchbase, Firestore, ClickHouse, Apache Druid, Elasticsearch, OpenSearch, Trino, Databend, BigQuery, Snowflake, Apache Spark, Apache Cassandra, Prometheus, InfluxDB (InfluxQL), InfluxDB 3 (SQL), Apache Kafka, etcd, Neo4j, Milvus, Qdrant, Weaviate, Oxia, S3-compatible object storage, Kubernetes, MQTT, RabbitMQ, OPC UA, MTConnect, Modbus, NETCONF, SNMP, Sparkplug B
  • Optional AI, off by default (own key): plain-English EXPLAIN on PostgreSQL, MySQL, SQLite, libSQL, DuckDB, Couchbase, ClickHouse, Apache Druid, Trino, Databend, BigQuery, Snowflake and Apache Spark. A read-only agent on PostgreSQL, SQLite, DuckDB, SQL Server, MySQL, Kubernetes, MongoDB, ClickHouse, libSQL, InfluxDB 3 (SQL), Elasticsearch, OpenSearch, Oracle, Db2 LUW, Apache Cassandra, Couchbase, Apache Druid, LibreDB, InfluxDB (InfluxQL), Weaviate and Qdrant never writes
  • Hardened: non-root, read-only rootfs, NetworkPolicy, PDB, HPA, Ingress/TLS
  • Self-hosted, air-gap friendly
  • amd64/arm64; Rancher, RKE2/K3s and Kubernetes validated per release
