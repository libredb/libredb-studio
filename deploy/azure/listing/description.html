LibreDB Studio is an open-source, self-hosted SQL IDE that runs entirely inside your own Azure subscription. This solution template deploys it on a single Ubuntu 24.04 LTS virtual machine, behind an automatically provisioned HTTPS endpoint, in about five minutes.

What you get

  • One workspace for thirteen engines - PostgreSQL, MySQL/MariaDB, Microsoft SQL Server (including Azure SQL), Oracle, SQLite, MongoDB, Redis, Couchbase, ClickHouse, Apache Druid, Elasticsearch, OpenSearch and Apache Trino.
  • A real editor - Monaco-based SQL editing with schema-aware autocomplete, formatting, query history and virtualized result grids that stay fast on large result sets.
  • AI query assistance - turn natural language into SQL, explain and optimize existing queries. You supply your own model provider key; no query data is sent anywhere you have not configured.
  • Schema and operations tooling - ERD diagrams, data profiling, EXPLAIN plans, slow-query and session views, and code generation.
  • Single sign-on - vendor-agnostic OIDC that works with Microsoft Entra ID, Okta, Auth0, Keycloak and any other compliant provider.

Why teams run it themselves

  • Your data never leaves your subscription. The application, its configuration store and every database connection stay inside your own Azure tenant.
  • No licence, no seat count, no telemetry. LibreDB Studio is MIT-licensed open source; this offer is free and you pay only for the Azure resources you deploy.
  • Private networking friendly. Reach databases over your virtual network, private endpoints or peered networks; restrict the web interface to a CIDR range at deployment time.

What this template deploys

  • An Ubuntu 24.04 LTS virtual machine of the size you choose
  • A virtual network, subnet and network security group (ports 80 and 443; SSH only if you ask for it)
  • A static public IP address with a DNS label
  • LibreDB Studio and a reverse proxy that obtains a free TLS certificate for that DNS name

After deployment

Open the URL shown in the deployment outputs and sign in with the administrator email and password you entered in the wizard. Application data is stored on the virtual machine's managed disk and survives restarts.
